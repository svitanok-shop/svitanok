СВІТАНОК — ВИПРАВЛЕННЯ МІСТ, ВІДДІЛЕНЬ ТА ПОКУПЦІВ

1. Firebase Console → Realtime Database → Rules. Збережіть копію старих правил. Вставте ПОВНИЙ вміст database.rules.json і натисніть Publish. Це надає адміністратору читання всього вузла /users, яке необхідне для списку покупців. Перевірте, що ви ввійшли під UID адміністратора, вказаним у правилах.

2. Для автоматичного пошуку населених пунктів та відділень Нової пошти потрібна Netlify Function novaposhta. У Netlify → Environment variables додайте NOVA_POSHTA_API_KEY (не в app.js). Перерозгорніть сайт через Git або Netlify CLI, щоб функція опублікувалася. Звичайне перетягування статичних файлів не гарантує розгортання функцій.

3. Перевірте URL https://ВАШ-ДОМЕН/.netlify/functions/novaposhta?type=cities&q=Львів . 404 = функція не опублікована; 503 = немає ключа; 200 з data = успішно.

4. Для Укрпошти зараз доступне ручне введення адреси й індексу. Цей ZIP НЕ реалізує автоматичний довідник відділень Укрпошти: для цього потрібна окрема інтеграція з офіційним API та відповідні права. Відстеження ТТН також потребує серверних ключів (див. README-TRACKING.txt).

5. Не надсилайте API ключі або Firebase service account у чат і не додавайте їх у публічні файли.
