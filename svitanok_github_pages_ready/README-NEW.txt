Світанок: нові функції
1. Завантажте файли на Netlify.
2. У Firebase Realtime Database → Rules замініть правила вмістом database.rules.json та Publish. Зробіть резервну копію старих правил.
3. Адмінка: Покупці, Статистика, Замовлення.
4. Профіль: шкала статусів. Товари: відгуки з фото та рейтингами.
5. Блокування обмежує відгуки, створення замовлень і чат, але не забороняє вхід до акаунта.
6. Статистика базується на записах замовлень, а не підтверджених платежах.
